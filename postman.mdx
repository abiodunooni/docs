## Setting up

<Steps>
  <Step title="Import">
    In Postman, **Import → File**, and select the downloaded `.json`. Folders, examples and auth come with it.

    You can also skip the download entirely — **Import → Link** and paste the URL:

    ```
    https://docs.quidax.com/postman/wallets.postman_collection.json
    ```
  </Step>

  <Step title="Set your key">
    Open the collection, go to **Variables**, and set `secretKey` to your key for that product. Auth is configured at collection level, so every request inherits it.

    | Collection | Variable | Format |
    | --- | --- | --- |
    | Ramp | `secretKey` | `sk_live_…`, sent as `x-private-key` |
    | Payments | `secretKey` | `sec_live_…`, sent as a bearer token |
    | Wallets | `secretKey` | Sent as a bearer token |
  </Step>

  <Step title="Check the base URL">
    `baseUrl` is pre-set to production for each collection. Leave it unless you have been given a different host.
  </Step>

  <Step title="Fill in path variables">
    Requests with `:user_id`, `:transaction_id` and similar expose them under the **Path Variables** table on each request. In the Wallets collection `user_id` defaults to `me`, so most requests run as-is.
  </Step>
</Steps>

<Warning>
  Set the variable as a **current value**, not an initial value, so your key is not written into the collection file if you export or share it.
</Warning>

## Things worth knowing

<AccordionGroup>
  <Accordion title="Payments Initialize needs the public key" icon="key">
    Collection auth applies your **secret** key to every request, but `Initialize a transaction` expects the **public** key — it will fail until you override it.

    On that request, open **Authorization**, set the type to **Bearer Token**, and paste your `pub_live_…` key. Everything else in the collection keeps using the secret.
  </Accordion>

  <Accordion title="These hit production" icon="triangle-exclamation">
    Every `baseUrl` points at a live host. Ramp and Wallets have **no sandbox**, so a successful `POST` moves real money.

    Payments has a separate test environment — set `secretKey` to a `sec_test_…` key and you are safe to experiment.

    <Card title="Testing" icon="flask" href="/testing" horizontal />
  </Accordion>

  <Accordion title="Query parameters start disabled" icon="sliders">
    Optional query parameters are included but unticked, so you can see what exists without sending empty values. Tick the ones you want.
  </Accordion>

  <Accordion title="Examples are illustrative" icon="code">
    Saved responses come from the API specifications, not from live calls. Treat them as shape references rather than current values — rates, fees and balances will differ.
  </Accordion>
</AccordionGroup>
