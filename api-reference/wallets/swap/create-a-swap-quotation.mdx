# Create Instant swap

This endpoint is used to generate an instant swap quotation. Please note that the instant swap quotation is valid for only 15 seconds. To refresh the swap and obtain a new quotation, you can use the Refresh Instant Swap endpoint. [https://docs.quidax.io/reference/refresh-instant-swap](https://docs.quidax.io/reference/refresh-instant-swap)
