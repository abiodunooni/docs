---
title: "Create a payment address"
---

Create a payment address for a wallet.  The address is generated immediately and returned in the API response.  Specify the network when creating the address. To see the networks available for each currency, use the [Fetch User Wallet](https://docs.quidax.io/reference/fetch-user-wallet)  endpoint.
