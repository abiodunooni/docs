Not every listed asset supports every action. Some can be traded but not sent or received, and some cannot have a wallet address generated at all. Check the Actions column before you build a flow around an asset.

<Warning>
  Retrieve the live list from the API rather than hard-coding this table. Assets and networks change, and a hard-coded list means a release every time one does.
</Warning>

## Networks

<Warning>
  The network must match the destination address. Sending an asset over a network the receiving wallet does not support loses the funds permanently — there is no recovery and no reversal.

  Validate the address before initiating a withdrawal.
</Warning>

A currency's wallet lists every network it runs on, each with its own `deposits_enabled` and `withdraws_enabled` flag. Read those rather than assuming a network supports both directions.
