The Wallets API gives your users their own crypto and fiat wallets on Quidax. Create sub-accounts, generate blockchain addresses, watch deposits arrive, send funds out, and trade — without running custody, node infrastructure or blockchain monitoring yourself.

## At a glance

| | |
| --- | --- |
| **Base URL** | `https://openapi.quidax.io/exchange-open-api/api/v1` |
| **Auth** | `Authorization: Bearer <secret_key>` |
| **Accounts** | One parent account, unlimited sub-accounts |
| **Assets** | BTC, ETH, USDT, USDC, XRP, LTC, BNB, SOL and many more |
| **Fiat** | NGN, GHS, XAF, XOF |
| **Rate limit** | 300 requests/minute, 20/second on address generation |

## How it fits together

<Steps>
  <Step title="Create a sub-account">
    One per customer. The parent account is addressed as `me`; sub-accounts by their user ID.

    <Card title="Sub-accounts" icon="users" href="/wallets/sub-accounts" horizontal />
  </Step>

  <Step title="Generate an address">
    Each sub-account gets wallets per currency, and you generate blockchain addresses against them.

    <Card title="Wallets and addresses" icon="qrcode" href="/wallets/addresses" horizontal />
  </Step>

  <Step title="Receive deposits">
    Funds arrive on-chain. Webhooks tell you when they are confirmed.

    <Card title="Deposits" icon="arrow-down" href="/wallets/deposits" horizontal />
  </Step>

  <Step title="Move money out">
    Send on-chain, internally between your own accounts, or to a bank account.

    <Card title="Withdrawals" icon="paper-plane" href="/wallets/withdrawals" horizontal />
  </Step>
</Steps>
